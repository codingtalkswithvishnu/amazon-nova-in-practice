# Industry pilot worksheet

Choose one task from a documented customer pattern. Record:

- Your requirement, permitted data and task owner.
- The current manual or software baseline.
- What the cited customer account actually establishes.
- Your proposed model, retrieval and review flow.
- Quality, latency and cost acceptance criteria.
- A held-out test set, operational failure path and cleanup owner.

A customer's reported result is evidence for its workload, not a forecast for yours.

Run commands from the **repository root** after completing the root README setup.

| File | Command or purpose |
| --- | --- |

Local verification: `python -m unittest discover -s tests -v`. Passing checks do
not establish live account access or task quality on your data.
