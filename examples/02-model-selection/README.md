# Model selection worksheet

1. State one user task, input type and required output.
2. Record the exact model/profile ID, permitted Regions, supported API and lifecycle.
3. Define accepted output shape and factual checks before comparing candidates.
4. Use the same held-out inputs. Record validity, accepted facts, latency and cost.
5. Keep a candidate only if it meets the documented acceptance criteria.
